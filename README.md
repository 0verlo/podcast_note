# podcast note

个人学习笔记。收听讲座、对谈类音频节目后，按固定工作流将内容提取为结构化的 Q&A 笔记，保留核心论点与待深挖线索。

## 目录结构

```
├── WORKFLOW.md              # 笔记提取工作流（执行设计，提取时照此操作）
├── check_note.py            # 审计脚本：格式 / 切分 / 覆盖 / 压缩比 / 锚点 / raw 改行
├── _concepts/               # 跨笔记概念索引（人物、学派与方法、核心概念、精神分析）
├── <节目名>/                # 按节目来源分目录
│   ├── raw/                 # 该节目的原始转写文本
│   │   └── 01_xxx.txt
│   └── 01_xxx.md            # 提取后的笔记
```

- 每个节目来源独立一个目录
- `<节目名>/raw/` — 音频转写原文，作为提取的输入素材
- `<节目名>/*.md` — 按 WORKFLOW 提取后的笔记成品，格式为模块化 Q&A + What's Left 线索区

## 设计方法论

WORKFLOW.md 只描述执行时需要知道的设计，设计背后的考虑记录在这里。

### AI 与程序的分工

AI 的产出灵活但不稳定，总结、切分、判断信息密度这类语义工作只能由 AI 完成。程序的产出不灵活但确定，同样的输入必然得到同样的输出。工作流让两者相互制约：AI 负责全部语义判断，程序核对这些判断的可量化后果是否落在约定范围内。

这一分工基于一条经验前提：AI 在几百字的小段落上做总结基本可靠，在数万字的长文本上做总结不可靠。讲者的信息密度在讲述过程中持续变化，为每一小段判断合适的压缩率、并严格按这个压缩率执行，是任务的核心，也是程序无法替代 AI 的部分。流程因此把整篇转写分解为几百字的段落，让每个 AI 判断都发生在可靠的小上下文里。

### 账本作为约束的载体

细切产出的 Q 列表某种程度上是一份账本：行范围、压缩比、锚点，都是 AI 在读小段原文时写下的承诺。写作发生在更长的上下文里，容易偏离；脚本逐条核对成品与账本，把小上下文里做出的判断带到写作阶段去约束执行。压缩比和锚点在细切阶段写定，写作阶段调整须更新账本且仍受全文压缩带约束。这样安排是为了避免声明被写作结果反向追认：若声明可以随写作结果任意改动，一致性核对就只剩自洽，约束会落空。

锚点申报只对声明压缩比低于 65% 的条目强制。压缩越深，取舍越多，失真风险越大；浅压缩接近原文转述，经验上基本不会失真。审计因此集中在取舍真正发生的地方，浅压缩条目的账本保持一行。

### 指标基底与倒退的终止

切分边界由 AI 自由划定，是流程中最上游的自由度，程序无法从语义上评判一个切分好不好。但坏切分能造成的实际危害集中在可量化的维度：段落过大时压缩判断失效（语料中覆盖超过 1600 字的条目全部严重失控）、切得过碎、内容被静默丢弃。边界位置本身的偏差是自限的：错放的内容会落入相邻条目，由那条 Q 自己的覆盖义务和压缩声明兜住。所以一层量化先验就足以约束切分自由，"谁来审计审计者"的追问在这里终止，无须更上层的审计。

基底数字取自已提交笔记的实测分布：

| 指标 | 当前值 | 作用 |
|---|---|---|
| Q 密度带 | 600–900 字/Q | 拦截切得过碎与漏切 |
| 单 Q 覆盖上限 | 1500 字 | 拦截压缩判断失效的大段落 |
| 全文压缩带 | 50%–70% | 锚定逐条压缩声明的总和，替代 AI 在全文尺度上不可靠的判断 |
| 执行偏差门槛 | 负偏超 15pp 打回 | 拦截写作阶段的细节丢失；单条正偏由全文压缩带把关 |
| 深压缩线 | 声明低于 65% 须申报锚点 | 把审计集中在取舍发生的条目 |

语料增长后用 `python3 check_note.py --baseline <好笔记...>` 回算实测分布，人工确认后修订脚本常数区与 WORKFLOW 中的对应描述。基底随语料修订，不在单次运行中自动漂移。

## Commit 格式

```
<一句话概述>

[Notes]     ← 笔记增删改
[Raw]       ← 原始素材增删
[Chore]     ← 工程及结构相关
[Format]    ← 内容格式/样式调整
```

按需使用相关分类，无变更的分类省略不写。

范例：

```
初始化笔记仓库

[Notes]
1.add 13_语言学相关对谈
2.add 37_相似性与关联

[Raw]
1.add 13_语言学相关对谈
2.add 37_相似性与关联

[Chore]
1.add WORKFLOW.md 笔记提取模板
2.add README.md
```
